Basic physics engine coded in Lua

Love2d has box2d fully integrated as a physics engine, but I didn't use it. Love is mostly used for drawing. Notably Triangualtion and convex shape checking are important to the code but not implemented by me.

With this project I wanted to figure out how game engines do physics. Turns out it boils down to 1 formula from actual physics (impulse formula with rotation) and the rest is mostly finding where and how to apply it.

I really could sit here for hours explaining all the cool algorithms that went into this but there are just way too much. I was coming back to this project from time to time implementing whatever I found interesting (This how soft bodies and Voronoi diagram you see in the background got there).

Theres a release available on github but it is outdated by quite a few commits. You can see everything in the gif though.
